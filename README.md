# Яйца Cloud для Android

Приложение сайта [Яйца Cloud](https://fggtf24-cyber.github.io/yaytsa-cloud/): лента, чаты и профиль в отдельном окне, уведомления о сообщениях, ответах и лайках.

## Установка

Скачайте `YaytsaCloud.apk` из [последнего релиза](https://github.com/fggtf24-cyber/yaytsa-cloud-android/releases/latest) и откройте. Новые версии приложение предлагает само.

## Как устроено

- Внутри живой сайт (WebView): новые функции появляются без обновления приложения.
- Сайт узнаёт приложение по `YaytsaCloudAndroid/` в User-Agent и пишет в мост `YaytsaAndroid.post(json)`: `theme`, `notify`, `google`, `auth`. Обратно — событие `yaytsa-app`: `go`, `google-cred`.
- Вход через Google — в обычном браузере, ответ принимает локальный адрес `127.0.0.1` (как в приложении для Windows).
- Уведомления: пока приложение живо — сразу; выгружено — фоновая проверка базы раз в ~15 минут.
